## 5. 本项目实际调用了什么

通过 `funasr.AutoModel` 加载三个官方预训练模型：

- `paraformer-zh`：中文高精度 Paraformer 语音识别模型；
- `fsmn-vad`：语音端点检测（VAD）；
- `ct-punc`：标点恢复。

调用代码位于 `src/transcribe.py`，核心为：

```python
from funasr import AutoModel
model = AutoModel(model="paraformer-zh",
                  vad_model="fsmn-vad",
                  punc_model="ct-punc")
result = model.generate(input=audio_path, batch_size_s=300)
```

随后把 `sentence_info` 中的 `start` / `end` / `text` 转换为本项目统一的
`start_ms` / `end_ms` / `text` 片段格式。

## 6. 为什么没有重新训练模型

FunASR 的 `paraformer-zh` 已在超大规模中文语音数据上预训练，对通用中文
会议转写已具备良好效果；课程目标是“集成调用”而非“训练模型”。重新训练需要
大量标注数据、GPU 与时间，且对本实验无必要收益。因此本项目直接复用预训练
权重，符合“参考开源项目”的课程要求。

## 7. FunASR 在整个系统中的位置

FunASR 位于“转写”能力层，是整个系统的数据入口：音频先经 FunASR 转写为带
时间戳的文本片段，后续关键词检索、时间定位、会议摘要均基于该转写结果。

```
音频 -> FunASR(paraformer-zh + fsmn-vad + ct-punc) -> segments
                                                       -> search
                                                       -> locate
                                                       -> summarize
```
