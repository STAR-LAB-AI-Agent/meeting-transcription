# 验收视频脚本（约 60 秒）

> 状态：**DEMO_VIDEO = PASS**。已用 Playwright 自动操作 Streamlit 真实录制完成，
> 成品见 `docs/demo/AI_Meeting_ASR_Demo.mp4`（55.6s，1280×720 H.264），
> 原始录制 `docs/demo/recording_raw.webm`，说明见 `docs/demo/DEMO_VIDEO_REPORT.md`。

> 以下为 1 分钟左右的录制脚本。可直接使用已生成的合成模拟会议音频
> `data/input/synthetic_meeting_demo.wav`（67.5s，TTS 合成，非真实会议），
> 或用 `scripts/generate_synthetic_meeting.py` 重新生成。

## 0-5 秒：开场

- 口播：“这是《智能体开发实战》第 15 题，AI 会议语音转写与检索智能体。”
- 屏幕：项目根目录 + 标题。

## 5-20 秒：上传音频并转写

- 打开 `python -m streamlit run app/streamlit_app.py`。
- 选择 `synthetic_meeting_demo.wav`，点击“开始转写”。
- 口播：“这是一段合成模拟会议音频，FunASR 正在把它转写成带时间戳的文字。”
- 屏幕关键信息：转写结果逐句显示，每句带 `HH:MM:SS` 起止时间。

## 20-35 秒：关键词检索

- 在“关键词”输入框输入“预算”，点击“搜索”。
- 口播：“搜索‘预算’，返回命中时间点和上下文。”
- 屏幕关键信息：多个命中片段 + 时间戳 + 上下文。

## 35-45 秒：时间定位

- 在“时间点”输入“01:30”，点击“定位”。
- 口播：“查看 01:30 附近说了什么。”
- 屏幕关键信息：目标时间点与对应会议内容。

## 45-55 秒：生成会议摘要

- 点击“生成会议摘要”。
- 口播：“自动生成会议摘要，包括主题、讨论点、决策和待办。”
- 屏幕关键信息：主题 / 概要 / 讨论点 / 决策 / 待办。

## 55-60 秒：架构与仓库

- 口播：“整体架构是 Agent → Skill → Script/CLI → FunASR，代码已提交到
  GitHub。”
- 屏幕：`docs/系统架构.md` 的架构图 + GitHub 仓库页面。
