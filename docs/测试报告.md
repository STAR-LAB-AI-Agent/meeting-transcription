  无空 segment，中文无乱码。

  - “智能体” 1 命中、“语音识别” 1 命中；
  - “FunASR” 0 命中（被 ASR 误识别为“翻AS二”）；
  - “GitHub” 0 命中（被误识别为“get how”）；
  - “量子火箭”（不存在）0 命中。

- 摘要：输出 topic/summary/key_points/action_items；无明确决策时输出
  “未识别到明确决策事项”，未编造。
- 演示级 CER：4.91%（13/265 字符），仅作为“合成会议识别结果”演示，不是模型
